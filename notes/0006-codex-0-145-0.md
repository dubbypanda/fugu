Codex is now pinned to 0.145.0

Fugu now targets Codex 0.145.0, up from 0.144.6. The launcher will offer to switch your Codex to it, and your existing Fugu configs and API key carry over unchanged.

0.145.0 is a sizable upstream release: it adds paginated thread history with search and resume, an /import that migrates Claude Code and Cursor settings, Amazon Bedrock support, audio input/output and realtime conversations, a stabilized multi-agent mode, and the GPT-5.6 model family. None of that changes how Fugu works — you reach the same Fugu models through the same Sakana API, with the same stream-resilience and safety settings as before.

Nothing is required on your part, and Fugu behaves the same as before. The Fugu config still pins remote plugins off ("remote_plugin = false" in the [features] block of ~/.codex/fugu.config.toml), as it has since Codex 0.143.0 began enabling them by default; remove that line if you want upstream's behavior.
