Codex is now pinned to 0.144.1

Fugu now targets Codex 0.144.1, up from 0.142.5. The launcher will offer to switch your Codex to it, and your existing configs and API key carry over unchanged. Codex 0.144.1 brings upstream's own installer reliability fixes and its new out-of-process code-mode host.

Nothing is required on your part, and Fugu behaves the same as before.

One thing worth knowing, because we deliberately held it back. From Codex 0.143.0, Codex enables remote plugins by default, which makes it fetch a plugin catalog over the network. Fugu talks to the Sakana API rather than OpenAI, and a version bump should not quietly change what your Codex reaches out to, so the Fugu config pins remote plugins off — alongside the app and image-generation features it already disabled. If you want them, remove the "remote_plugin = false" line from the [features] block of ~/.codex/fugu.config.toml.
