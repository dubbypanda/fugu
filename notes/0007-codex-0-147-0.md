Codex is now pinned to 0.147.0

Fugu now targets Codex 0.147.0. The launcher will offer to switch your Codex to it, and your existing Fugu configs and API key carry over unchanged.

This spans a sizable stretch of upstream releases (0.146 and 0.147): it adds portable Agent Plugins with catalog search, conversations organized into manually ordered sections with incremental browsing of long transcripts, an opt-in MCP 2026-07-28 protocol, redaction of secrets and bearer tokens from displayed commands, and cached web search plus remote compaction for Amazon Bedrock. None of that changes how Fugu works — you reach the same Fugu models through the same Sakana API, with the same stream-resilience and safety settings as before.

Nothing is required on your part, and Fugu behaves the same as before. The Fugu config still pins remote plugins off ("remote_plugin = false" in the [features] block of ~/.codex/fugu.config.toml), as it has since Codex 0.143.0 began enabling them by default; remove that line if you want upstream's behavior.
