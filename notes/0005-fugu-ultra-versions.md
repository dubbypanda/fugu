Fugu Ultra is now version-pinned

The /model picker now lists Fugu Ultra as two explicit versions instead of one: fugu-ultra-v1.1 (the current Ultra) and fugu-ultra-v1.0 (the previous one). Selecting a version pins you to it, so a later Ultra release will not change the model under you unless you switch to it yourself. The unversioned "fugu-ultra" entry is no longer shown on its own.

Nothing is required on your part. If you were using Fugu Ultra, pick fugu-ultra-v1.1 for the same model you had — your configs and API key are unchanged, and fugu and fugu-cyber are unaffected.
